# Vocal más común

Crea un función que reciba un texto y retorne la vocal que más veces se repita.
- Ten cuidado con algunos casos especiales.
- Si no hay vocales podrá devolver vacío.

#

Calculate where a robot (its final coordinates) will be in a grid represented by the "x" and "y" axes.

Create a function that receives a text and returns the vowel that appears the most times.  
- Be mindful of some special cases.  
- If there are no vowels, it can return an empty string.
